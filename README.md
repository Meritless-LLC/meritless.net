# meritless.net

Website for Meritless LLC — plain static HTML/CSS, no build step.

- `index.html` — home page
- `support.html` — App Store support URL
- `privacy.html` — App Store privacy policy URL
- `terms.html` — terms of use
- `404.html` — not-found page (served by GitHub Pages for any missing URL)
- `CNAME` — custom domain for GitHub Pages
